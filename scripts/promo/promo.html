How WebSeal works
01 · RELEASE

CI hashes every file

into a manifest served at /.well-known/webseal.json
02 · ANCHOR

The hash goes on ENS

text record webseal. With ENSv2, the CI key can change only that record.
03 · CHECK

The extension checks the page

every script, style and the HTML. A mismatch blocks wallet signing.

No WebSeal server. The browser checks against ENS directly.
